# マスク作成支援ツール

VRChat向けのマスクテクスチャ作成・編集ツールです。グレースケールマスクをUnityエディタ上で直感的にペイントできます。

## 目的

VRChatアバターのシェーダー設定で使われるマスクテクスチャ（2ndカラーブレンド、影マスク、エミッションマスクなど）を、外部ペイントソフトを使わずにUnity上で直接作成・編集できるようにします。

## 基本機能

### マスクペイント

グレースケール（0.0〜1.0）のマスクをブラシで描画します。

- **ペンツール**: 指定した濃度でマスクを塗る（ブラシサイズ・濃度調整可能）
- **消しゴムツール**: マスクを消去（強度調整可能）
- **ぼかしツール**: マスクの境界をなめらかにする
- **スポイトツール**: キャンバスから濃度値をサンプリング
- **エッジクランプ**: UVアイランドの外へのはみ出しを防止

### UVアイランド選択

メッシュのUVアイランド単位でマスクを一括塗りつぶし・消去できます。

- クリックでアイランドを選択して塗りつぶし/消去
- 選択範囲のマージン調整（-5〜+5px）
- メッシュのトポロジーから接続されたアイランドを自動検出

### Undo/Redo

テクスチャ解像度に応じてメモリを自動管理する履歴システムを搭載しています。

- 最大50ステップの履歴
- 解像度に応じた動的なメモリ管理

### インポート/エクスポート

- PNG形式でのインポート・エクスポート
- ドラッグ＆ドロップによるインポート
- ブレンドモード選択（上書き / 暗い方優先 / 明るい方優先 / 乗算）

### 見え方プレビュー

マスクが実際のシェーダーにどう影響するかをシーンビューでリアルタイム確認できます。

- lilToon / Poiyomi シェーダー対応
- プレビューカラーの変更

## 動作環境

- Unity 2019.4 以降
- ComputeShader対応GPU

## 使い方

1. メニューの「キメラヘアマスター > マスク作成支援ツール」からウィンドウを開く
2. 対象のGameObjectとマテリアルを選択
3. ペンツールやアイランド選択で塗る
4. 見え方プレビューで確認
5. エクスポートしてマテリアルに適用
